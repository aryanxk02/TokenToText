01 / Begin here

From zero to generated text.

MiniLLM is deliberately small. Install two dependencies, run the tests, train on the built-in corpus, and sample from the checkpoint.

Install

python3 -m pip install -r requirements.txt
python3 -m pytest -q

Train & generate

python3 -m examples.train_tiny --steps 400
python3 -m examples.generate \
  --checkpoint artifacts/minillm.npz \
  --prompt "the " \
  --tokens 120
✦
What counts as success?
On the first run, look for a decreasing loss and a working checkpoint. Coherent language comes later—and requires enough data and training.

05 / Input

Characters become numbers.

A language model cannot consume strings directly. `CharTokenizer` builds a vocabulary from the corpus and maps every character to an integer ID.

Two reserved tokens are always present: <pad> and <unk>. Unknown characters fall back to ``.

06 / Learning objective

Predict the next token.

Training shifts a sequence by one position. The model sees the input row and is graded against the target row.

input
the mo
target
he mod

For a batch, both arrays have shape (batch, time). The causal mask ensures position t cannot see target information from the future.

08 / Context

Attention lets tokens look left.

Each representation creates a query, key, and value. Queries ask what information is relevant; keys describe what each position offers; values carry the information.

the attention equation
Q, K, V = x₀ Wqkv
scores  = QKᵀ / √head_dim
weights = softmax(scores)
output  = weights V

The causal rule

At position t, attention can use positions 0…t, never t+1…. The upper triangle is replaced with a very negative score before softmax.

09 / Transformer block

Attention, normalization, and memory.

MiniLLM uses one decoder block. Residual paths keep the original signal available while each sub-layer learns a useful transformation.

input→causal self-attention→residual add
LayerNorm→linear → GELU → linear→residual add
LayerNorm→vocabulary logits

LayerNorm

Normalizes features for each token independently, then restores useful scale and offset through learned gamma and beta.

MLP

Transforms each position independently. The inner dimension d_ff is wider than d_model, giving the network room to compute.

10 / Objective

Scores become a learning signal.

The output head turns each hidden vector into one score per vocabulary item. Softmax turns scores into probabilities; cross-entropy rewards the correct next token.

logits = final_representation @ Wlm + blm
probabilities = softmax(logits)
loss = -log(probabilities[correct_token])

11 / Learning mechanics

No autograd. Every derivative is visible.

loss_and_backward() walks the computation graph in reverse and returns one gradient array for every parameter. The gradient shapes exactly match the parameter shapes.

loss↓output head↓LayerNorm↓MLP + GELU↓attention↓embeddings
∂
How do we know the math is right?
The finite-difference test compares the analytic gradient to (loss(θ+ε) − loss(θ−ε)) / 2ε. Matching values are strong evidence that the implementation is wired correctly.

    steps=400,

Adam maintains moving averages of gradients and squared gradients. MiniLLM also clips gradient elements to [-1, 1] as a simple stability guard.

13 / Inference

Generation is a loop with memory.

Start with a prompt, predict one token, append it, and predict again. The model keeps only the most recent context_length tokens.

Temperature

Divide logits by temperature before softmax. Lower values are more predictable; higher values are more varied.

--temperature 0.7

Top-k

Keep only the k highest-scoring candidates. This prevents very unlikely tokens from being sampled.

model.generate(ids, max_new_tokens=120,
    rng=rng, temperature=0.7, top_k=8)
14 / Persistence

Save the learned machine.

A checkpoint stores the model parameters, configuration, and tokenizer vocabulary in a NumPy .npz file.

model.save("artifacts/minillm.npz", tokenizer.to_dict())

model, tokenizer_data = MiniGPT.load("artifacts/minillm.npz")
tokenizer = CharTokenizer.from_dict(tokenizer_data)
Local experiments only. Checkpoint loading uses NumPy object deserialization. Do not load untrusted checkpoint files.

16 / When things break

Common problems, clear fixes.

ModuleNotFoundError+

Run examples from the repository root as modules: python3 -m examples.train_tiny. This keeps the package on Python’s import path.

Loss becomes NaN+

Lower the learning rate, reduce model width, verify the corpus is non-empty, and confirm that context_length < len(token_ids). The implementation already uses stabilized softmax and gradient clipping.

Generated text is nonsense+

Train longer, use a larger and cleaner corpus, and tune temperature. A few dozen steps only verifies the pipeline; it does not create a useful language model.

Runtime is slow+

This implementation favors clarity over performance. Reduce batch size, context length, or model width while experimenting.
